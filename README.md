# Hello, World Assignment
Create a C program that prints "Hello, World!"

Also creade a `Makefile` to build the program.

## Starting point

Start from the following skeleton:

```c=
#include <stdio.h>

int main(void){
    ...
}
```

## Build

Build the program using:

```console
make
```

## Test

To test, run:

```console
./helloworld | grep 'Hello, World!'
```
